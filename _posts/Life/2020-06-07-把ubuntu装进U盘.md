## legacy模式

在启动时狂按F12，选择USB，按理说已经可以启动了。但是并没有成功启动。

究其原因，应该是使用uefi模式启动的缘故。我们需要设置电脑以legacy模式启动。那么怎么设置呢？

1. 开机时狂按F2，进入bios，使用→键选择boot选项， 找到UEFI，下拉菜单选择legacy First。

2. Disabled掉OS Optimized Defaults和Secure Boot。

接下来再狂按F12进入即可。

## PPT模式——都是显卡惹的祸

然而进入ubuntu之后情况并非所想。ubuntu卡成了ppt，甚至连terminal都进不去。无法进行任何改善。

于是我选择用VMWare启动。

`新建虚拟机->添加硬盘->选择usb所对应的物理磁盘->使用全盘`

开机，便可以看到我们已经装好的ubuntu了。后来查了查，可能是因为本电脑装了显卡，而ubuntu系统没有自带驱动，需要安装nvidia驱动。

而VMWare内无法识别本机的硬件，所以只能先装个驱动过后再处理。

使用PPA仓库

```shell
$ sudo add-apt-repository ppa:graphics-drivers/ppa
$ sudo apt update
```

由于显卡无法识别，无法查看推荐的显卡驱动，直接下载一个最新版的。

```shell
$ sudo apt install nvidia-driver-440
```

然后就可以在物理机上以不怎么ppt的模式享用ubuntu了。

## 全自动修复

```shell
$ sudo apt update
$ sudo apt upgrade
```

执行命令之后重启，ppt模式成功关闭。
